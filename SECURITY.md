# Seguridad

## Versiones soportadas

Mientras el proyecto se encuentre antes de la version `1.0`, solamente la
ultima version disponible recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No abras un issue publico con detalles que permitan explotar una
vulnerabilidad. Utiliza la opcion **Report a vulnerability** de GitHub Security
Advisories en el repositorio.

Incluye una descripcion, pasos para reproducirla, impacto estimado y sistema
operativo utilizado. No adjuntes credenciales ni datos obtenidos de redes sin
autorizacion.
